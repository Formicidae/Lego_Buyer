# Bundled build orders

LDraw models of official sets, used for the step-by-step Build tab. A file named `<set_num>.mpd`
(Rebrickable set number, e.g. `75954-1.mpd`) is imported automatically the first time that set's
build order is requested; the Build tab's import form can replace it at any time.

| File | Model author | Source |
|---|---|---|
| 75953-1.mpd Hogwarts Whomping Willow | Stefan Frenz [smf] | https://forums.ldraw.org/thread-24235.html |
| 75954-1.mpd Hogwarts Great Hall | Stefan Frenz [smf] | https://forums.ldraw.org/thread-24235.html |
| 75948-1.mpd Hogwarts Clock Tower | Stefan Frenz [smf] | https://forums.ldraw.org/thread-24235.html |

All three are redistributable under CCAL 2.0 (see each file's header). The author notes they omit
stickers and minifigures, 75953 uses 40232 for the owl, and 75948 substitutes a sword and the clock-face
prints — the importer reports those as unmatched or guessed parts.
